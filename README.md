## 📌 О проекте

**«Умный планировщик»** — это веб-приложение, разработанное в рамках курсовой работы по дисциплине «Проектный практикум». Проект направлен на решение проблемы перегруженности студентов и неэффективного распределения учебной нагрузки.

Система объединяет принципы тайм-менеджмента (матрица Эйзенхауэра, метод «Помидора», техника временных блоков) в автоматизированный инструмент, адаптирующийся под индивидуальные особенности пользователя.

---

## 🎯 Цели проекта

1. Автоматизировать процесс планирования учебных и личных задач
2. Снизить уровень стресса и когнитивной перегрузки у студентов
3. Обеспечить сбалансированное распределение нагрузки с учётом:
   - срочности и важности задач
   - индивидуальных биоритмов и хронотипа
   - энергозатратности разных типов деятельности
   - фиксированных временных блоков (учеба, работа)

## 🚀 Установка и запуск

### Требования

Для работы приложения необходимо:

- **Веб-сервер:** Apache / Nginx
- **PHP:** версия 7.4 или выше
- **MySQL:** версия 5.7 или выше
- **phpMyAdmin** (рекомендуется для управления БД)
- **Локальный сервер:** OpenServer / XAMPP / MAMP / Denwer

---

### Пошаговая установка

#### 1. Клонирование репозитория

```bash
git clone https://github.com/ваш-username/smart-planner.git
cd smart-planner
```

#### 2. Настройка веб-сервера

Поместите папку проекта в корневую директорию вашего веб-сервера:

- **OpenServer:** `./domains/`
- **XAMPP:** `./htdocs/`
- **MAMP:** `./htdocs/`

#### 3. Создание базы данных

1. Откройте phpMyAdmin (обычно `http://localhost/phpmyadmin`)
2. Создайте новую базу данных, например `smart_planner`
3. Выберите кодировку `utf8_general_ci`

#### 4. Импорт структуры БД

Импортируйте файл `daily-planner.sql` в созданную базу данных:

- В phpMyAdmin перейдите в созданную БД
- Нажмите «Импорт»
- Выберите файл `daily-planner.sql`
- Нажмите «Выполнить»

#### 5. Настройка подключения к БД

Отредактируйте файл `bd.php` и укажите параметры подключения:

```php
$host = 'localhost';        // Хост
$user = 'root';             // Имя пользователя
$password = '';             // Пароль (по умолчанию пустой)
$database = 'smart_planner'; // Имя вашей базы данных
```

#### 6. Запуск приложения

Откройте в браузере:

```
http://localhost/smart-planner/
```

#### 7. Регистрация и вход

1. Перейдите на страницу регистрации (`register.php`)
2. Создайте учётную запись
3. Войдите в систему (`login.php`)
4. Начните использовать личный кабинет

### Возможные проблемы и решения

| Проблема | Решение |
|----------|---------|
| **Ошибка подключения к БД** | Проверьте параметры в `bd.php` |
| **Страница не загружается** | Проверьте, что проект в корне веб-сервера |
| **Ошибка 404** | Проверьте пути к файлам |
| **Сессии не работают** | Проверьте настройки PHP |
